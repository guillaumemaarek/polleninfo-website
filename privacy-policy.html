Politique de confidentialité

Dernière mise à jour : 26 mars 2026

🔒 Pollen Info s’engage à protéger votre vie privée et à assurer la transparence sur l’utilisation des données, conformément au Règlement Général sur la Protection des Données (RGPD).

1. Éditeur de l'Application

L'Application Pollen Info est éditée par :

  • Guillaume Maarek
  • 📧 Contact : guillaumemaarek@gmail.com
  • 🌐 Site : https://polleninfo.fr

2. Données collectées

L'Application adopte une approche minimaliste et respectueuse de la vie privée.

2.1 Données directement identifiantes

L'Application ne collecte aucune donnée directement identifiante, telle que :

  • nom
  • prénom
  • adresse e-mail
  • adresse postale

2.2 Données techniques et d'usage (analytics)

Afin d'améliorer l'Application, certaines données d'usage sont collectées via Amplitude.

🔗 https://amplitude.com

Ces données incluent :

  • événements d'utilisation (navigation, interactions)
  • événements techniques (sessions, performance)
  • événements liés aux notifications et onboarding

Exemples :

  • app_opened
  • screen_view
  • city_selected
  • pollen_data_loaded
  • onboarding_completed
  • notification_opened

👉 Ces données :

  • sont pseudonymisées
  • ne sont pas utilisées à des fins publicitaires
  • ne sont pas revendues

2.3 Identifiants techniques et préférences

L'Application collecte également :

  • un identifiant technique (device_id)
  • des préférences utilisateur :
    • ville par défaut (nom et code INSEE)
    • types de pollen sélectionnés

Ces données sont utilisées uniquement pour :

  • le bon fonctionnement de l'Application
  • la personnalisation des notifications

👉 Le device_id est un identifiant pseudonymisé qui, conformément au RGPD, peut être considéré comme une donnée personnelle sans permettre une identification directe.

3. Finalités du traitement

Les données sont utilisées uniquement pour :

  • améliorer l'expérience utilisateur
  • analyser l'utilisation de l'Application
  • assurer les fonctionnalités (notifications, préférences)
  • diagnostiquer les problèmes techniques

👉 Aucune utilisation à des fins :

  • publicitaires
  • commerciales
  • de revente de données

4. Base légale

Les traitements reposent sur :

  • le consentement (pour les analytics, si applicable)
  • l'intérêt légitime (fonctionnement technique de l'Application)

5. Partage des données

Les données peuvent être traitées par des services tiers :

  • Amplitude (analytics)
  • Supabase (stockage et base de données)

👉 Ces services :

  • sont utilisés uniquement pour le fonctionnement de l'Application
  • n'exploitent pas les données à des fins commerciales

Aucune donnée n'est vendue, louée ou partagée à des fins publicitaires.

6. Stockage et sécurité

  • Les données sont hébergées au sein de l'Union Européenne
  • Les accès sont strictement limités
  • Certaines données restent stockées localement sur l'appareil

Les données sont conservées uniquement le temps nécessaire.

7. Droits des utilisateurs

Conformément au RGPD, vous disposez des droits suivants :

  • accès
  • rectification
  • suppression
  • opposition
  • limitation

📧 Contact : guillaumemaarek@gmail.com

8. Utilisateurs mineurs

L'Application est accessible à partir de 9 ans.

Aucune collecte intentionnelle de données sensibles concernant les mineurs n'est effectuée.

9. Sources de données externes

L'Application utilise des données publiques provenant d'APIs :

Données environnementales (Google)

  • Fournisseur : Google
  • APIs utilisées :
    • Weather API
    • Air Quality API
    • Pollen API

👉 Données fournies : informations environnementales agrégées, non personnelles

Données environnementales (France)

  • Fournisseur : Atmo France
  • API : ATMO Data
  • Données : indices de pollution et pollen

Données administratives

  • Fournisseur : République Française
  • API : geo.api.gouv.fr
  • Données : communes (nom, code INSEE, etc.)

👉 Ces APIs ne reçoivent aucune donnée personnelle de l'utilisateur.

10. Modifications

Cette politique peut être mise à jour à tout moment.

Les utilisateurs seront informés via :

  • une mise à jour de l'Application
  • ou le site https://polleninfo.fr

11. Contact

Pour toute question relative à la protection de la vie privée ou à cette politique, vous pouvez contacter :

📧 guillaumemaarek@gmail.com
